## Step-by-Step Experiment Design Protocol

### Step 1: Pre-Register Metrics and Test Datasets

1. **Define Task & Splits:**
   - Select evaluation datasets covering in-distribution (ID) and out-of-distribution (OOD) tasks (e.g., compositional reasoning, algorithmic tasks, domain shift).
   - Partition into calibration/validation (for hyperparameter tuning) and evaluation test splits (strictly evaluated once).
2. **Pre-Register Performance Metrics $M$:**
   - Task performance: Accuracy, Exact Match (EM), Perplexity, F1.
   - Resource overhead: Mean inference latency (ms), peak VRAM (MB), total inference FLOPs, forward-pass count.

---

### Step 2: Construct the Compute-Matched Baseline Suite

Never compare iterative SCBI against an unaugmented greedy baseline alone. You must match the compute budget:

| Evaluation Dimension | SCBI Configuration | Matched Baseline 1: Standard | Matched Baseline 2: Sampling / Search | Matched Baseline 3: Test-Time Compute |
| :--- | :--- | :--- | :--- | :--- |
| **Forward Passes** | $K \times T$ passes | Greedy decoding (1 pass) | Best-of-$N$ with $N = K \times T$ | Self-Consistency (Wang et al.) with $N = K \times T$ |
| **Inference FLOPs** | Model FLOPs $\times (1 + \alpha)$ | Baseline FLOPs | $N \times$ Baseline FLOPs | $N \times$ Baseline FLOPs |
| **Memory Footprint** | Model + State $z_t$ + Basis $B_t$ | Model only | Model only | Model only |
| **Backbone State** | Frozen ($\Delta\theta = 0$) | Frozen ($\Delta\theta = 0$) | Frozen ($\Delta\theta = 0$) | Frozen ($\Delta\theta = 0$) |

---

### Step 3: Configure the 5 Mandatory Ablations

Every experimental matrix must include all 5 ablations:

1. **Ablation 1 (Random Selection):**
   - Retain candidate generator $\mathcal{G}$, replace $\arg\min_k \mathcal{E}(B_{t,k})$ with $k \sim \text{Uniform}(1, K)$.
   - *Target:* Validates whether objective $\mathcal{E}$ actually provides optimization guidance.
2. **Ablation 2 (Static Basis):**
   - Fix $B_t = B_0$ across all iterations $t=1,\dots,T$.
   - *Target:* Isolates dynamic basis invention from fixed linear projection.
3. **Ablation 3 (Null / Shuffled Objective):**
   - Reverse or permute the self-consistency loss metric $\mathcal{E}$.
   - *Target:* Tests whether optimizing $\mathcal{E}$ is constructive or if any perturbation suffices.
4. **Ablation 4 (Budget Scaling Curve):**
   - Measure $M$ across iteration counts $T \in \{0, 1, 2, 3, 5, 10\}$.
   - *Target:* Discovers scaling properties, saturation points, and degradation thresholds.
5. **Ablation 5 (Zero-State $z_t = \emptyset$):**
   - Reset $z_t$ to zero at each step, preventing accumulated memory.
   - *Target:* Tests the value of persistent state evolution $\mathcal{T}$.

---

### Step 4: Verification Checklist Against Data Leakage

- [ ] Test set labels $y$ are completely withheld from the candidate generation and evaluation loops.
- [ ] No test-set statistics (mean, variance, embeddings) are shared across test instances.
- [ ] Model KV-cache and temporary tensors $z_t, B_t$ are wiped clean between instances.
- [ ] Backbone model weights are checksummed before and after inference runs to confirm $\Delta\theta=0$.

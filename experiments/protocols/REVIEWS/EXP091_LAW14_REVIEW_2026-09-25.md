## 2. BINDING RULING on the §0 action-text coupling — ACCEPTED as (a)

The draft changes action texts from EXP090's bare names (`A`, `C`) to the spaced single-token BPE form
(`" "+A`, `" "+C`). I rule this **a legitimate part of the G1' repair, not a substantive redesign**:

1. **The bare form was never coherently embeddable.** The registered extraction is "final-token hidden state"
   of the action text. Bare `"Mars"` fragments to 2 tokens ([46, 1032]); its "final-token state" would be the
   state after a BPE fragment, not a representation of the entity. The old G1 existed precisely to prevent
   this incoherence. Leaving action texts bare while guarding in-prompt occurrences would make G1' guard
   something other than the embedded material — the coupling is what keeps the guard load-bearing.
2. **Same lexical item, natural BPE form.** Every entity occurrence in every benchmark prompt IS the spaced
   form (my cover check: the covering token is `ĠMars` etc., the identical token id produced by standalone
   `" "+entity` encoding — guaranteed by BPE determinism on the same character sequence). The action
   embedding uses the same token the model sees in running text. This is not a different candidate.
3. **Symmetric treatment.** A and C receive identical treatment; any geometric effect of the leading space
   applies equally to both options, and the decision is `argmax` over the two. The Law #7 1:1 balance
   (each option name appears exactly once in the premise) is preserved; §5 is byte-identical to EXP090.
4. **Falsification logic untouched.** Bar (≥38/60, P=0.0260), §7.1 TOTAL tree, and the positional diagnostic
   adjudicate the resulting accuracies whatever the action-text form. §7 is byte-identical to EXP090.
5. **The alternative is the bigger change.** Span-readout over fragments (mean/last-fragment pooling) would
   introduce new unregistered readout choices; the spaced form preserves the registered single-token
   final-state extraction with minimal perturbation.

**Interpretation bound (disclosed, not a fix):** the option embedding is the embedding of a token that also
occurs in the state text (premise contains each option token once — the 1:1 balance). Any token-identity
contribution to cosine similarity is therefore symmetric across options and cancels in the argmax — but a
CONTINUE must not be misread as evidence of "semantic alignment" specifically. It remains evidence of
exploitable zero-shot decision signal, which is exactly the registered §1 question. This is already covered
by §5 (balance + diagnostic, not exclusion) and caveat 1 (probe-at-heart); no protocol change is needed,
and I note it here only so the bound is on the review record.

**Restructure not required.** The question, bar, tree, fence, and decision licenses are unchanged; severing
the EXP089→EXP090→EXP091 lineage would discard the Law #9 reuse justification and the archive provenance
pin while testing the same question. (Cf. LOG-348: restructure rejected as process theater.)

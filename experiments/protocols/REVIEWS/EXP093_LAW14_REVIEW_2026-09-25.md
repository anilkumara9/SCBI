## 1. Load-bearing defect F1 — §3.1 direction construction is identically zero

### The identity

Draft §3.1 defines, for each item i: c^{−i}(j) = mean{ h(k) : k≠i, k≠j, target(k)=target(j) }, and v^{−i} = normalize( mean_{j≠i} [c^{−i}(j) − h(j)] ).

**Theorem (verified):** mean_{j≠i}[c^{−i}(j) − h(j)] = **0 exactly**, for every i.

*Proof sketch.* Group the sum by target class. For a class M with |M|=m not containing i: Σ_{j∈M} c^{−i}(j) = Σ_{j∈M} (1/(m−1))Σ_{k∈M,k≠j} h_k = Σ_{k∈M} h_k (each h_k appears m−1 times). For the class containing i: Σ_{j∈M,j≠i} c^{−i}(j) = Σ_{k∈M,k≠i} h_k (each appears m−2 times). Summing over classes: Σ_{j≠i} c^{−i}(j) = Σ_{j≠i} h(j). The difference is zero. ∎ — this is the oldest identity in statistics (residuals from class means sum to zero), preserved exactly under LOO.

### Numeric confirmation (reviewer-executed)

- Synthetic data (60 items, 20 classes ×3, random embeddings): ‖pre-normalization mean‖ = **5.4e-17 – 6.9e-17** for all tested i — machine-epsilon zero.
- Real archived layer-11 embeddings (`exp092_embeddings.npz`, read-only): max over all 60 items = **7.178e-08** — float32 accumulation noise around the analytic zero.

`normalize()` of this vector divides by zero → NaN. As written, the bundle's G2 assertion (‖v^{−i}‖=1) **must** fail → RUN-INVALID. The experiment is unexecutable, not merely weak.

### Required fix — replace §3.1's construction (exact replacement text)

The drafter's *intent* ("the shared static direction that prototypicalizes any item") is preserved; the *formula* was wrong. Any linear average of prototype-residuals is zero by the identity above, so the fix uses per-item normalization before averaging — yielding the **maximum-average-cosine shared correction direction**:

> For each item i ∈ {1…60}, define the **leave-one-out prototype residual**:
> - h(i) = layer-11 final-token embedding of item i.
> - c^{−i}(i) = mean{ h(k) : k ≠ i, target(k) = target(i) } — the class prototype of i's target, excluding i (mean of 2 items; always defined).
> - r_i = c^{−i}(i) − h(i); the bundle asserts ‖r_i‖ > 1e-9 for all i (else RUN-INVALID — an item coinciding with its LOO prototype makes the direction undefined).
> - u_i = r_i / ‖r_i‖ — the unit LOO correction direction.
>
> The **shared direction for item i** is v^{−i} = normalize( (1/59) Σ_{j≠i} u_j ), computed **without item i's data** (zero leakage at test time), without model gradients, without new extraction.
>
> *Mathematical note (registered):* the unnormalized mean Σ_j[c(j)−h(j)] is identically zero (residuals-from-class-means sum to zero, exactly, including under LOO — the v0.1 construction was degenerate by this identity). Per-item normalization before averaging breaks the zero-sum; v^{−i} is the unit vector maximizing average cosine with the 60 LOO correction directions.
>
> **Coherence diagnostic (registered, reported, non-binding):** the bundle reports the mean pairwise cosine among {u_i} and the pre-normalization ‖(1/59)Σ_{j≠i}u_j‖.
>
> **Registered measurement (reviewer-verified on the archived `.npz`, 2026-09-25):** min_i ‖r_i‖ = 1.3352 (no degeneracy); mean pairwise cosine(u_i,u_j) = **−0.0160**; pre-normalization shared-direction norm ∈ [0.0246, 0.0444]; all 60 v^{−i} unit-norm, mutually near-identical (max pairwise cosine 0.9554, as expected for LOO variants).
>
> **Registered implication:** the shared component is ~3% coherent — the "shared static direction" hypothesis is *a priori* weak (correction directions are nearly mutually orthogonal, slightly anti-aligned by the zero-sum constraint). The experiment is therefore a genuine falsification attempt: KILL is the expected outcome, and a CONTINUE would be surprising and informative. The v0.1 degeneracy and this replacement are recorded here per the program's error-preservation standard.

### Conforming edits (part of F1)

- **§1(4) license paragraph:** replace "The registered v (§3) is the leave-one-out prototype-residual direction — the average 'toward correct class prototype' correction" with "The registered v (§3) is the LOO maximum-average-cosine shared correction direction — the unit vector best aligned with the 60 per-item 'toward correct class prototype' corrections. Under H1 (a shared decision-relevant component exists in the layer-11 geometry), ⟨∇ₕm, v⟩ > 0 on average, so Δm > 0."
- **G2:** conform to the new construction — assert ‖r_i‖ > 1e-9 ∀i; recompute {u_i}, {v^{−i}} from the `.npz` (no cached directions); assert ‖v^{−i}‖=1 ∀i; report the coherence diagnostic.
- **Appendix A:** add considered-and-rejected alternative — "Top-PC of the residual matrix (data-driven shared direction): rejected — less interpretable than the hypothesis-driven max-cosine correction direction; PC1 need not align with prototypicalization."

## 2. Additional required fixes F2–F9

**F2 — G4 margin tolerance is self-defeating (guard defect).** Draft G4 requires "mean logit-margin within 1e-6 of −0.0018." The registered reference −0.0018 is rounded to 4 decimals; the independent recomputation (LOG-4338) gives −0.001819. |−0.001819 − (−0.0018)| = 1.9e-5 > 1e-6: a *correct* run fails G4 → spurious RUN-INVALID. **Fix:** require "mean logit-margin within 1e-4 of the registered reference −0.0018 (full-precision −0.001819 per LOG-4338; the 1e-4 tolerance covers the recorded rounding precision)."

**F3 — C-first-only full significance is unhandled (decision-tree totality defect).** §5's parenthetical routes "C-first-only significance" to "KILL-with-note," but KILL's *condition* ("every McNemar p ≥ 0.05") is then unsatisfied, PIVOT(a) doesn't match, and PIVOT(b) requires a failed bar — while KILL's *licensed claim* ("no significant transfer at any phrasing") would be factually false. **Fix:** replace the parenthetical with an explicit arm — "(c) **Contrary-stratum significance:** C-first meets all three bars (Δ_C ≥ 0.10, p_C < 0.05, mono_C) while the aggregate fails CONTINUE → PIVOT to mechanism forensics. Rationale: contradicts the registered O1 directional prior; with nominal stratum p-values the false-positive risk is material, so no CONTINUE (no surprise-hunting reward) — but KILL's licensed claim would be false, so forensics with a new pre-registration before any build."

**F4 — N-vs-B significance routing is ambiguous.** If −v *hurts* significantly (N-vs-B p < 0.05) while P-vs-B is non-significant, that is directional evidence with a wrong-sign prediction — currently it falls into KILL, which mislabels it. **Fix:** amend PIVOT(b) to "some McNemar p < 0.05 (P-vs-B **or** N-vs-B) but the 10pp bar or monotonicity fails" and add "Significant N-vs-B with non-significant P-vs-B routes here (forensics), not to KILL."

**F5 — G5 acceptance criteria unregistered.** "Proves by execution" with no criteria is not a guard. **Fix:** register — "(i) on a single-item probe, hooked final-position residual = unhooked value + α·v^{−i} within relative 1e-6; (ii) all other positions change by < 1e-9 absolute; (iii) condition B (hook disabled) logits bit-match a hook-free reference run."

**F6 — KILL program-consequence overbreadth.** §5 KILL says "the static-injection family stands down at layer 11," but the fenced scope (§4.4, §8.2) is the *shared* static direction — per-item static directions are explicitly EXP094+ material (§7). **Fix:** qualify to "the *shared* static-injection family stands down at layer 11 (per-item static directions remain EXP094+ material per §7)."

**F7 — Licensed CONTINUE claim must carry the strata.** The aggregate CONTINUE can be A-first-driven (O1); §8.3 says the caveat "travels," but the claim template doesn't carry it. **Fix:** append to the §5 CONTINUE licensed claim: "Stratum breakdown: Δ_A = __, Δ_C = __ (registered §4.2); the O1 phrasing-sensitivity caveat (§8.3) is part of this claim."

**F8 — G4 exact-reproduction needs environment pinning.** "The model is deterministic" is true only under identical execution conditions; thread-count differences can flip near-zero margins. **Fix:** add to §6 G4 / §9 — "the bundle pins torch intra-op thread count to the EXP092 extraction value, records it in the run meta, and asserts it before condition B."

**F9 — Tie rule must match S2's.** G4's exact 36/60 reproduction is well-defined only under S2's tie-breaking. **Fix:** register S2's tie rule explicitly (cite the EXP092 scorer's handling), or assert the scorer had zero ties (making the rule moot for G4); the >5% RUN-INVALID rule stands for P/N conditions.

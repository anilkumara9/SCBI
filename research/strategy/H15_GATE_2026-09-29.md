## The six mandatory items

### 1. Exact question

[HYPOTHESIS] Does EXP111's trained-head signal (24/30 test accuracy, G=0.0000,
layer-20, frozen backbone) replicate on a newly constructed second
template-decorrelated bench — new templates, new entity sets, new distractor
geometry — under EXP111's exact pinned discipline (bench 2's own 60 items,
own labels, own embedding extraction)?

### 2. Decision changed

- **CONTINUE (generality hypothesis):** test accuracy **≥ 20/30** (one-sided
  binomial p ≤ 0.0494 vs chance, the EXP111 bar) **AND** G < 0.30 → the trained
  head extracts a template-invariant feature (subject-position readout
  surviving meaning-preserving rephrasing, per the EXP107 kill-test logic);
  the output-side program's single positive result earns a generality claim,
  and the GPU head-training proposal (re-licensed under decorrelated-bench
  discipline by EXP111 §6) is strengthened beyond one bench.
- **Generality KILLED (H15's KILL bar):** test accuracy **≤ 18/30** (p ≥ 0.1808)
  or **G ≥ 0.30** (template-detector signature: a ≥5-item gap at the pinned
  N_F=N_T=15 denominators) → the bench-1 result is a bench-specific artifact;
  the generality hypothesis is KILLED. EXP111's bench-1 **observation stands**
  (Law #8 — nothing retroactively un-happens) but its CONTINUE is
  **downgraded**: reclassified as a bench-specific correlation, not an
  apparatus-level transfer claim. The output-side readout room is retired.
- **HELD:** 19/30 with G < 0.30 (the EXP111 razor case) → underpowered zone;
  no rerun, no larger-N rescue (the EXP106 no-rescue discipline applies).

The dispatch text's "KILL" and the brief's "downgrade" are reconciled here:
**KILL applies to the H15 generality hypothesis; EXP111's bench-1 observation
is never un-happened — it is reclassified, not erased.** Law #11 tags the
two layers explicitly.

### 3. Cheapest test

One 60-item bench authored independently (new vocabulary, new templates,
four 15-item cells per the EXP107 discipline: phrasing × flipped), 60
layer-20 final-token embedding extractions on CPU (~30–60 min, Δθ=0), then
EXP111's pinned head protocol on the archived embeddings. $0 CPU. No
generation anywhere in the design (the EXP108/EXP109 RUN-INVALID hard
constraint carries over).

### 4. Mathematical license

[OBSERVATION] EXP111's 24/30 with G=0.0000 (one-sided p ≈ 0.0014 vs chance)
is a real above-chance signal on bench 1 with no template-detector
signature. [PROPOSITION] The decorrelated-bench discipline is a pinned,
independently reviewed construction protocol (LOG-4535 bench builder,
LOG-4564/4566 Law #14 review of the H5 pre-reg). [HYPOTHESIS] The same
pinned protocol applied to an independently constructed bench: replication
is expected under generality, collapse-to-chance or template-signature
under bench-specificity. The license is one-shot — the pinned split seed,
head spec, and bars carry over byte-verbatim; no sweeps, no per-layer tuning
(Law #7), no seed re-rolls.

### 5. Quantitative prediction (directions only — no outcome licensed)

- **Under generality (template-invariant mechanism):** test accuracy ≥ 20/30
  with G < 0.30 — the same bars as bench 1, because the bars are properties
  of the protocol, not the bench.
- **Under bench-specificity (artifact hypothesis):** test accuracy collapses
  toward chance (≈15/30, below the 20/30 bar), or the EXP107 template-detector
  signature reappears (G ≥ 0.30) — the two ways an artifact dies are both
  pre-registered.
- **Power:** n=30 test items; the bar clears α=0.05 one-sided. Fine-grained
  comparisons between bench-1 and bench-2 accuracies are NOT licensed (the
  30/30 split is powered for the bar, not for cross-bench effect sizes —
  no post-hoc cross-bench t-test).

### 6. Breaking point

**Bench construction is the breaking point.** If no valid second bench can
be constructed, the lane is void before any head is trained — no
contaminated-bench run is ever licensed. Concretely, the bench-construction
lane must pass ALL of these before H15 pre-registration proceeds:

1. **Independent item authoring:** new vocabulary, new templates, no shared
   template strings with the EXP107 bench, no reuse of bench-1 items
   (re-using them is Law-#9 theater — explicitly barred).
2. **Decorrelation checks pass on bench 2 alone:** four balanced 15-item
   cells (phrasing × flipped); a pure template detector scores ≈ 30/60;
   entity-rank correlation with the EXP107 bench ≤ 0.10.
3. **Template decomposition independently pinned** (the EXP107 equivalent of
   `QUESTION_SUFFIX` byte-exact + canonical-order construction), so the
   meaning-preserving flip can be independently verified.
4. **Own tuple[0]-label pinning procedure** (Law #7 — see below), executed

If any of 1–4 fails → **the item dies at bench construction; no head is
trained; the log records the construction failure.** A further apparatus

pass fails or train/test ID overlap → RUN-INVALID (the EXP111 §3.4/§3.3
discipline).

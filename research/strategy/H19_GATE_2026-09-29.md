## The design problem (adjudicated)

EXP117's generation channel is dead on the entity-name shape
(0/10 parseable). EXP119's plan-prefix composition died structurally:
the plan block sits between the question and the answer slot, so the
last plan token (`ĠE`, id 444) replaces the baseline's `?` (id 32) in
the [-3:] tail — the pinned identity rule fired on item 0, RUN-INVALID,
§0(6) breaking point realized, independently replicated tokenizer-only.

**Placement adjudication (this gate):** two candidate placements exist.
(A) Plan between the premise and the question — the plan arm ends with
the **byte-identical** `" Question: Who is higher in rank? Answer:"`
tail as the baseline; the final token run is tokenizer-invariant by
construction. (B) Plan after the bench question's `?` but before
`Answer:` — the final [-3:] tail then ends with the plan's last token,
which is exactly EXP119's structural failure re-created; placement (B)
would need the plan to end in `?` on every item, which is not licensed
and re-admits the untested tokenization surface. **This gate licenses
only placement (A).** Placement (B) is not a new channel — it is the
EXP119 composition with a name change, and is barred under Law #4
(it would be a re-run of a retired composition without a new licensed
mechanism).

With placement (A), the readout position's tokens are textually
identical in both arms; the [-3:] identity pin is still mechanically
verified on all 60 items (it holds by construction, but the pin is the
evidence, not the argument).

## The six mandatory items

**1. Exact question.** On the 60-item EXP107 template-decorrelated
bench, does inserting the EXP113-cleared T2-P2 plan text between the
premise and the fixed question tail (placement (A)) change the frozen
backbone's zero-generation logit-level decision — argmax over the two
pinned entity token ids at the final position, EXP112's apparatus —
relative to the no-plan verbatim baseline, paired per item?

**2. Decision changed.** Bars carried over from H14's signed pre-reg
(§4) — the hypothesis, bench, logit channel, item count, and the
statistical object (paired discordant counts on n_valid items) are
identical; only the plan placement changed, which alters the
identity-break but not the decision statistic. Carrying the same bars
is a fidelity-to-license requirement, not a new choice:
- **CONTINUE:** one-sided paired McNemar exact p ≤ 0.05 with b > c →
  the plan-inserted pipeline changes decisions at the logit level; the
  pipeline enters the adaptive-loop designs as a registered component
  (later, separately pre-registered lanes only), under the §-fence
  below.
- **KILL:** net (b−c) ≤ 0 → plan-conditioning moves nothing even at
  the logit level through a working composition — the planning
  question is retired on the EXP107 bench's logit channel (stronger
  than EXP119's RUN-INVALID, which tested nothing).
- **HELD:** net > 0 but p > 0.05 → indeterminate; licenses nothing,
  retires nothing, no re-runs.
- **RUN-INVALID:** any Phase-0 gate, pin, reproduction check, or the
  n_valid ≥ 48/60 gate fires → apparatus failure; the hypothesis gets
  no verdict.

**3. Cheapest test.** Two-step, both $0 CPU: (i) tokenizer-only
verification of the [-3:] identity on the placement-(A) composition for
all 60 items (~minutes, no model contact) — adjudicates the breaking
point before anything else; (ii) if (i) passes, the EXP119 apparatus
with only the plan placement changed: 60 T2-P2 planner generations
+ 120 logit forwards, Δθ=0, LOG-331 pin before/after, baseline
reproduction 60/60 vs EXP112's archived readout, G1 ≥ 0.01 per arm,
baseline-arm variation gate. No cheaper test answers the planning
question: both prior channels died before any decision data existed.

**4. Mathematical license.** Three bound clearances compose the
license: EXP112's HELD (the zero-generation logit decision channel
works on this exact bench); EXP113's apparatus CONTINUE (T2-P2
elicitation works, 60/60 parseable); EXP119 Phase-0a 10/10 (the planner
transfers to the EXP107 bench). EXP119's §0(6) breaking point
("tokenization effects break the channel") is the one that killed the
prefix composition — and placement (A) removes its structural cause:
the readout-region tokens are textually identical between arms, so
tokenization effects cannot break the pinned region. License stated:
*a composition whose readout-region tokenization is invariant across
arms licenses a paired comparison without the EXP119 identity break* —
with the mechanical pin as the evidence.

**5. Quantitative prediction (directions only).** Under a
plan-steering effect, b > c with one-sided p ≤ 0.05 → CONTINUE. Under
no effect, b ≈ c (net ≈ 0 → KILL). The tokenization-identity pin
holds by construction in placement (A) and is verified item-wise
before any forwards. No directional effect size is licensed.

**6. Breaking point (as written).** The [-3:] tokenization-identity
pin is carried over verbatim from the H14 pre-registration §3.7 as the
gate: **if the placement-(A) composition breaks the [-3:] identity on
ANY item — `tokenize(CONTEXT_PLAN)[-3:] != tokenize(CONTEXT_BASE)[-3:]`
— the run exits RUN-INVALID immediately, before any forwards are run.**
The composition is a draft until this pin passes on all 60 items in a
tokenizer-only pre-check. Carried verbatim alongside: Phase-0a
(<8/10 planner-valid → RUN-INVALID), the baseline-reproduction check
(≠60/60 vs EXP112's archived readout → RUN-INVALID), the n_valid ≥
48/60 gate, and the deterministic re-read ×2. Any of these fires and
the hypothesis gets no verdict.

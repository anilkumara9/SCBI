do per-sample anti-steerable fractions and coherence diagnostics change the

adaptive-vs-static comparison?

## 3. Method

[DEFINITION] **Anti-steerable item (decision-change operationalization):**
an instance the intervention moves the *wrong way* — base correct →
condition wrong. These are exactly McNemar corruptions `c`. **Anti-steerable
fraction** = c / N per condition, N = 60.

[NOTE — the Tan gap] Tan et al.'s "anti-steerable" is logit-difference
opposite to intent. A margin-based version of that (e.g., margin moved
against intent on already-correct items) would be a *margin* endpoint, and
the audit's Finding 3 invalidated margin endpoints as causal evidence
(B_wrong: Wilcoxon p ≈ 1.2e-08 with b = c = 0). Per the sprint's own
endpoint ruling ("signed outcome ledgers (not margins — the ledger is
decision changes, which already satisfies O5)"), only the decision-change
operationalization is licensed for the gate decision. Margin statistics are
reported in §5 as **exploratory context only**, never as gate evidence.

[ASSUMPTION] For static B_agg, intent = rescue. For already-correct items
(34/60 in EXP066), "anti-steerable" is defined only by flips (no decision
harm ⇒ not anti-steerable by this operationalization).

Gates (accepted, [ARBITRARY] where tagged): ≤5% → premise withdrawn;
(5%, 15%] → middle band; >15% → adopt the harm-ledger gate.

[INTERPRETATION] These show high directional agreement among
per-vocabulary *aggregate* directions — the opposite of what Braun's
diagnostic flags (low agreement ⇒ unreliable steering). But [ASSUMPTION,
unstated in archive] this proxy is confounded: per the audit's Idea-5
hygiene point, raw cosines were never mean-centred and may be inflated by
shared anisotropy; Braun's diagnostic needs per-pair Δh agreement, which is
gone. **Verdict on coherence: unmeasured — not high, not low.**
The sprint's degenerate branch anticipated exactly this: the real payload
of P3 was always the coherence machinery, and the archive cannot run it.

[OPEN] Whether centred per-pair directional agreement would be high or
low — answerable only by re-running the contrast construction with
per-pair Δh archiving (a re-analysis of the *same* support set; new GPU

## 7. Verdict — which branch fires

1. **Anti-steerable fractions are 0.0% for every condition in both runs**
   (EXP066 from the verified per-instance ledger; EXP065 exactly from
   c = 0 aggregates). The ≤5% branch fires — and as the adversarial review
   predicted, it fires degenerately: b = c = 0 was already established.
2. **The methodological premise is WITHDRAWN**: Tan et al.'s ~1/3
   anti-steerable average does not apply to this setting. Our ΔM = 0
   stands as a **true per-sample zero** — no hidden harm, no mismeasured
   aggregate. No gating metric is needed for the static-vs-bridge
   comparisons already run.
3. The (5%, 15%] middle band does not fire; the >15% branch does not fire.
   **No harm-ledger amendment to the signed EXP068/070 evaluators is
   required on P3 grounds → no Law #14 re-review triggered by this
   analysis.**
4. Coherence: unmeasured (archive gap). The premise-withdrawn branch's
   "AND coherence high" conjunction is therefore only half-satisfied —
   the fraction half. Recorded as a **partial firing**: the fraction
   condition is met degenerately; the coherence condition is *open*.
5. Sensitivity band for the standing verdicts: anti-steerable fraction
   carried as **0%** for EXP065/066 static-injection verdicts.

## 9. Residual uncertainties

1. **Operationalization gap vs Tan.** The licensed gate uses
   decision-change anti-steerability (flips); Tan's construct is
   logit-difference direction. If harm lives in margins without flips,
   the gate is blind to it — but the audit's Finding 3 rules margin-harm
   out as a causal endpoint, so this is a deliberate, disclosed
   limitation, not an oversight.
2. **EXP065 item identity is gone.** If a future question needs
   EXP065's per-item records (e.g., which items the bridge rescued on
   160m vs 410m), the answer is permanently unavailable.
3. **Coherence is the unanswered half of P3.** The honest status is
   "open," and the only path to closing it is a new execution that
   archives per-pair Δh — worth considering as a cheap adjunct to a
   future contrast-construction run, not as a standalone experiment.

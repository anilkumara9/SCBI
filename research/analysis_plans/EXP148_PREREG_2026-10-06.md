## 0. The question (unchanged from S7-1)

**[HYPOTHESIS]** A standard frozen transformer can simulate writable key–value memory in context: explicit WRITE/READ prompting discipline lets it externalize intermediate deductions as discrete tokens and re-attend to them, growing multi-hop capability without new architecture — beating budget-matched chain-of-thought.

**Breaking point:** On the powered design (n=180, §2), the scratchpad arm shows no advantage over budget-matched CoT (one-sided McNemar p ≥ 0.1, 95% CI for the net rate excluding +10pp) with the discipline verified delivered (guard (e)) and the budget-match comparability verified (guard (f′)) → **KILL** the J7 hypothesis. The missing ingredient is architectural, not disciplinary.

**Scope fence [DEFINITION]:** This experiment tests J7 — discipline vs architecture as the missing ingredient for Δθ=0 capability growth — at **Pythia-410m only**. It licenses no claim about other models, other scales, or other model families. Cross-family generality is bounded by EXP145's independent KILL/PIVOT; nothing here re-opens it.

**What this pre-registration does not do:** it does not repair, reopen, or re-read EXP147 (HELD stands); it does not change the model, the bench, the prompts, the budgets, or the decision bars; it does not touch the v102 paper or any killed lane; it does not license execution (verification SIGN + CEO authorization still required).

## 2. Power analysis (inherited from S7-1 §2 — scoring-agnostic license) [FACT]

Paired design: per item, b = S-correct/C-wrong, c = S-wrong/C-correct; q = P(b), r = P(c), net = q−r, d = q+r. McNemar power depends on (q, r, d) — **not on marginal accuracy** — so the S7-1 license transfers across the scoring change. All figures exact (binomial enumeration, α=0.05 one-sided), computed from first principles in the S7-1 drafting lane.

### 2.1 CONTINUE-bar power (one-sided McNemar p < 0.05)

| q | r | net | d | n=180 |
|---|---|---|---|---|
| 0.15 | 0.05 | 0.10 | 0.20 | 0.906 |
| 0.175 | 0.075 | 0.10 | 0.25 | 0.830 |
| 0.20 | 0.10 | 0.10 | 0.30 | 0.761 |
| 0.225 | 0.125 | 0.10 | 0.35 | 0.700 |

**Reading [INTERPRETATION]:** n=180 clears 80% power at +10pp for d ≤ 0.30 (MDE80 ≈ +10pp); at d=0.35 power is 0.70 (MDE80 ≈ +11pp).

### 2.2 KILL-bar operating characteristics

P(KILL fires) = P(one-sided p ≥ 0.1 AND two-sided p ≥ 0.1 AND 95% CI upper < +0.10):

| Truth | n=180 |
|---|---|
| Null, d=0.20 | 0.812 |
| Null, d=0.25 | 0.728 |
| Null, d=0.30 | 0.650 |
| True +10pp (q=0.15, r=0.05) | 0.028 |
| True +15pp (q=0.20, r=0.05) | 0.0005 |

[NOTE]: 95% Wald CI uses SE = √[(b+c) − (b−c)²/n]/n (S7-1 §2.2 convention). False-CONTINUE under null at n=180 ≤ 0.035 across d ∈ [0.15, 0.40].

**Reading [INTERPRETATION]:** the KILL bar fires 65–88% under true null at n=180 — a powered null. False-KILL under a true +10pp effect < 3%: the bar does not kill real effects.

### 2.3 Upper-bound caveat (review advisory iii — registered)

[CAVEAT]: the compositional strata sit at 0.96–0.98 under first-token scoring (near ceiling). If compositional items contribute ~0 discordant pairs, the S−C comparison is effectively powered on the transitive strata alone, and **the power figures above are upper bounds**. The design remains valid — the ceiling biases toward HELD (wide CIs), never toward false KILL or false CONTINUE. Disclosed, not designed around; the pooled primary stands (Law #9 — no post-hoc stratum fishing; stratum breakdowns descriptive only).

## 3. Frozen decision bars (S7-1 §3, verbatim)

- "ΔM_scratchpad ≤ ΔM_budget-matched-CoT": gains over the same baseline B; gain_S − gain_C = acc_S − acc_C (paired per-item correctness under §5.3 scoring). KILL = conjunction: (i) S vs C one-sided McNemar (H1: S>C) p ≥ 0.1, AND (ii) S vs C two-sided McNemar p ≥ 0.1, AND (iii) 95% Wald CI for net δ̂=(b−c)/n entirely below +0.10 (upper < +0.10).
- "scratchpad > baseline but ≤ matched CoT → PIVOT": KILL fires (or S vs C p ≥ 0.1) AND S vs B one-sided McNemar (H1: S>B) p < 0.05.
- CONTINUE: S vs C one-sided p < 0.05 AND net δ̂ ≥ +0.10.
- KILL is scoped: "discipline adds nothing *over budget-matched CoT*" — does not rule out sub-10pp effects or architectural writable memory.

### 5.3 Scoring (registered, deterministic) — THE REPAIR

**[DEFINITION — first-token scoring]** (the single substantive delta vs S7-1):
1. **B arm:** take the full generation → normalize (lowercase, strip punctuation, collapse whitespace — identical to S7-1 §5.3 step 2) → take the FIRST whitespace-delimited token → exact match vs normalized gold → 1, else 0.
2. **C/S arms:** take text after the LAST occurrence of `ANSWER:` → normalize → take the FIRST whitespace-delimited token → exact match vs gold → 1, else 0. No `ANSWER:` in the generation → 0 (unchanged from S7-1; no post-hoc rescue).
3. Primary metric: per-item correctness per arm. All verdict statistics are paired McNemar on (S, C) and (S, B) correctness pairs. No LLM judge (Law #13).

**Why this is the hypothesis, not a new one [INTERPRETATION — reviewed, LOG-4954]:** J7 is about reasoning capability; S7-1's scoring conflated reasoning with format compliance, and EXP147 proved format compliance fails independently on base Pythia. First-token scoring isolates the reasoning outcome. Symmetric across arms: every arm is scored on its first committed answer token; C/S reasoning happens before `ANSWER:`, so the scored token is post-reasoning in all arms.

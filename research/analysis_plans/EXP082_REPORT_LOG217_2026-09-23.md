## 6. L1 mathematical license — the three lemmas reproduced (promotion record)

**Lemma 1 (foil-suppression lemma).** [THEOREM] Let W_U ∈ ℝ^{V×d} be the frozen
unembedding matrix, x ∈ ℝ^d the final-token residual, logits ℓ = W_U x.
For unit v̂ ∈ ℝ^d, scalar α, token y: the perturbation x ← x + αv̂ shifts the
y-logit by Δℓ_y = α·(W_U[y,:]·v̂) = α‖W_U[y,:]‖₂·cos(v̂, ŵ_y).
*Proof:* Δℓ = W_U(αv̂); take the y-th row. ∎
With w_t = W_U[t_i,:], w_f = W_U[f_i,:], b̂_i = (w_t−w_f)/‖w_t−w_f‖₂, v̂ = b̂_i,
α_run > 0: **cos(−b̂_i, ŵ_{f_i}) ≥ 0.9 ⟺ Δℓ_{f_i} ≤ −0.9α_run‖w_{f_i}‖₂**.
*Proof:* Δℓ_{f_i} = α_run(w_{f_i}·b̂_i) = −α_run‖w_{f_i}‖₂cos(−b̂_i, ŵ_{f_i});
with all quantities nonzero and α_run > 0 the inequalities are equivalent. ∎

**Lemma 2 (mirror bound).** [THEOREM] d_i := cos(−b̂_i, ŵ_{f_i}) =
(‖w_f‖ − ‖w_t‖cosθ)/‖w_t − w_f‖, cosθ = (w_t·w_f)/(‖w_t‖‖w_f‖). Hence
d_i ≥ 0.9 ⟺ ‖w_f‖ − ‖w_t‖cosθ ≥ 0.9‖w_t − w_f‖; at cosθ = 0 ⟺
‖w_t‖/‖w_f‖ ≤ √(0.19/0.81) ≈ 0.4843. Equal-norm orthogonal rows ⟹
d_i = 1/√2 ≈ 0.7071 < 0.9: the 0.9 bar fires only on foil-row dominance.

**Lemma 3 (joint-firing lemma).** [THEOREM] On any item, d_i ≥ 0.9 ∧ c_i ≥ 0.9
⟹ cosθ ≤ −0.62. *Proof:* let γ = arccos(0.9) ≈ 25.84°; the firings give
angle(b̂,ŵ_t) ≤ γ and angle(b̂,−ŵ_f) ≤ γ. Spherical triangle inequality:
angle(ŵ_t,−ŵ_f) ≤ 2γ. But angle(ŵ_t,−ŵ_f) = π − θ, so π − θ ≤ 2γ and
−cosθ = cos(π − θ) ≥ cos(2γ) = 2(0.9)² − 1 = 0.62. ∎
G4 verified the lemma's consequent on every both-fire item (none existed; the
lemma stands unrefuted).

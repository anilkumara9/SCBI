## Binding defects (must be fixed before SIGN)

**D1 — §2.1 power-table SE/power numbers are inconsistent with the stated formula.** Both drafts. Formula: SE(θ) = √[(d−net²)(1/n₃+1/n₂)], n=380/level. Independent recomputation:

| (d, net) | True SE_diff | True power (δ=+0.10, 1-sided α=0.05) | Table claims |
|---|---|---|---|
| (0.30, 0.20) | 0.0370 | 0.86 | 0.0397 / 0.81 |
| (0.32, 0.20) | 0.0384 | 0.83 | 0.0410 / 0.79 |
| (0.36, 0.20) | 0.0410 | 0.79 | 0.0438 / 0.76 |
| (0.30, 0.25) | 0.0354 | 0.88 | 0.0385 / 0.82 |

The table's SE values are ~7% higher than the formula's outputs; powers correspondingly understated. The design decision (n=380/level + Step-0 exact-power recomputation + registered n-raise rule) is *safer* than stated, but Law #2 requires constants to be computed, not improvised. **Fix:** recompute the table from the stated formula; correct the design §2 narrative ("≈80% power at d ≤ 0.32, ~76% at d = 0.36" → ≈0.83–0.86 at d ≤ 0.32, ≈0.79 at d = 0.36).

**D2 — Reverse dose-response P(KILL) miscomputed.** Both drafts §2.1: "under true δ = −0.10, P(KILL fires) ≈ 0.81." Recomputed: Φ((0.10 − 1.96·SE)/SE) = Φ(0.7427) = **0.77** at the true SE (0.71 at the table's inflated SE). Neither is 0.81. **Fix:** replace with the recomputed value from the corrected SE.

**D3 — Study (b) portability-pilot forward cost wrong by ~4.5×.** Pre-reg §1.4 and §5.5: "≈ 46k forwards + ≈ 600 portability-pilot forwards." Recomputed: (p2) B-pilot 20×15 = 300 forwards; (p3) S-pilot 20×120 = 2,400 forwards; total ≈ **2,700** forwards. Guard (g) ≤ 50k still holds (45,900 + 2,700 = 48,600 < 50,000), so the design remains in budget — but the stated design cost is wrong (Law #2). **Fix:** correct to ≈2.7k in both places and re-assert the guard-(g) margin explicitly (48.6k ≤ 50k).

**D4 — 4-hop exploratory trigger worded inconsistently between drafts.** Design §2: "guard (h) projects ≤ 48h for a third level." Pre-reg §5.4: "guard (h) at Step 0 projects the 2-level run at ≤ 48h wall." These are different conditions; the pre-reg's is the operable registered one. **Fix:** reconcile both drafts to one registered trigger (recommend the pre-reg's: 2-level projection ≤ 48h at Step 0).

**D5 — The n-raise rule can breach guards (g)/(h) with no registered outcome.** Pre-reg §2.1: if exact power < 0.80, n rises to the smallest even integer with exact power ≥ 0.80. But raising n raises forwards and wall time against the fixed caps (g) ≤ 200k and (h) ≤ 72h — e.g., at pilot d = 0.45 the rule demands n ≈ 508/level → ≈259k forwards > 200k. No outcome is registered for this case. **Fix:** register the mechanical rule — after the n-raise computation, re-project forwards and wall time at Step 0; if either cap would be violated, study (a) STOPS at design cost (logged HELD). A computation, not a choice.

**D8 — The Step-0 power rule's input does not exist for study (a).** Pre-reg §2.1: "the execution lane computes exact binomial power at Step 0 from the pilot discordant-pair rate." But study (a)'s Step-0 dry run is **B-arm only** (20 items) — it produces no S−C discordant pairs. (For (b) this is covered: the CAVEAT registers the d ∈ [0.20, 0.35] assumption with a CEO-decides fallback.) **Fix:** register an explicit source for the (a) pilot rate — either (i) add a 20-item C+S pilot at Step 0 (cost 20×240 = 4,800 forwards; forward budget becomes 193,800 + 300 + 4,800 = 198,900 ≤ 200k — register the updated budget), or (ii) carry EXP148's realized d = 0.3556 as the planning value with the n-raise rule keyed to the first-block discordant rate.

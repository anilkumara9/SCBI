# S5-3 Report — Paired decode probes for the eight killed EXP077 variants

**Date:** 2026-09-28 | **Lane:** S5-3 (licensed LOG-4391) | **Compute:** $0 CPU only, no GPU contact

## Question

For the eight killed EXP077 variants, were their coordinates decodable-but-causally-inert,
or did the variants never encode the target information?

## Method (licensed, no improvisation)

EXP092's signed decode protocol, applied per variant to the archived intervention directions:
- **Representation:** 1-D coordinates `z_i = d_v · h_i`, where `h_i` are the EXP092-B
  layer-20 final-token embeddings (layer index 20 = EXP077's `target_layer=20`; same frozen
  Pythia-410m backbone, same layer, same 1024-dim space). This is the "paired" design:
  same bench, same labels, same statistical machinery as EXP092.
- **Statistic:** leave-one-out 1-NN accuracy from the squared 1-D distance matrix
  (functions imported **verbatim** from `score_exp092.py` — not reimplemented).
- **Null:** B=1,000 stratified (domain × phrasing) label permutations, `random.Random(9207+b)`.
- **Guards:** exact float nearest-neighbor ties → RUN-INVALID (§3); zero null spread → RUN-INVALID (G4 §6).
- **Bar:** Bonferroni `p < 0.05/8` **and** `(accuracy − null q95) ≥ 0.10` (10pp).
- **Decision table:** clears bar → *decodable-yet-inert* / CONTINUE; fails bar → *never-decodable* / PIVOT.

**Variant → direction map** (from `exp077_vectors.pt`):
| Variant | Arm | Direction |
|---|---|---|
| V1 radial α=0.25 | C2 | `v_hat` |
| V2 radial α=0.5 | C3 | `v_hat` |
| V3 radial α=1.0 | C4 | `v_hat` |
| V4 radial α=2.0 | C5 | `v_hat` |
| V5 angular (cone) | C9 | `v_hat` (cone center; cone = {u : angle(u,v_hat) ≤ 30°}, verified min cos = 0.86602531) |
| V6 control | C10 | `r_vec` (control-cone center; cos(v_hat, r) = 0.019, i.e. ~random) |
| V7 offset | C6 | `v_hat_c` (offset-removed direction, exactly as archived; cos(v_hat, v_hat^c) = 0.68) |
| V8 replication | C3 vs C1 | `v_hat` |

**Scale-invariance lemma** [FACT]: 1-NN neighbor ordering on 1-D projections is invariant to
positive rescaling, so α is decode-irrelevant; V1–V4 and V8 share one probe direction.
The eight arm-level probes therefore reduce to **three distinct directions** — reported, not hidden.

## Instrument checks

- **D1a machinery check (gating):** synthetic 1-D data with known class structure →
  acc=1.0000, p=0.0010, effect=+0.85 → instrument **LIVE**. The 1-NN + permutation machinery
  detects 1-D information when present; the variant nulls are real nulls, not deafness.
- **D1b label-informed direction (diagnostic, no veto):** a direction built from the labels to
  spread the 20 classes → acc=0.0500, p=0.745. Follow-up: top label-informed directions
  (centroid-PC1: acc=0.10, p=0.23; centroid-PC2: acc=0.05, p=0.47) also fail everywhere.
  [OBSERVATION] 1-D entity-decodable information at layer-20 is weak along *any* direction
  tried — the variant probes' failure is not a sensitivity artifact of one construction.
- **V6 as negative control:** the random direction r_vec gives p=0.0499 nominally — correctly
  *rejected* by both the Bonferroni bar (0.00625) and the 10pp effect bar (+0.017). The two-part
  bar does its job: a chance-level wiggle does not pass.
- **Guards:** no exact distance ties tripped; all null spreads non-zero (G4 passes).
- **Determinism:** re-run produces byte-identical results JSON (all RNG seeded).

## Interpretation (labeled per Law #11)

- [OBSERVATION] No variant direction's 1-D coordinates decode the entity label above the
  licensed bar. The strongest probe (V6, random direction) reaches only acc=0.1167 with
  effect +0.017, far below the 10pp bar.
- [INTERPRETATION] Per the licensed decision table, all eight variants are **never-decodable /
  PIVOT**: the Gap-4 geometric rooms (radial scalings of v_hat, the 30° cone family, the
  control cone, the offset-removed direction) did not encode the target information in any
  1-D-decodable form. The wall is informational (empty rooms), not causal (inert coordinates).
- [INTERPRETATION] This is consistent with — and sharpens — the EXP077 GPU verdict (branch (c)
  NEITHER): the directions that failed to move decisions also carry no decodable task
  information. The belief-change logic fires on the PIVOT branch.
- [CAVEAT] The decode target is **target-entity identifiability** (EXP092's licensed
  operationalization of "task information"), not EXP092's… correction: not EXP077's
  relational-vs-neutral construct. Testing whether v_hat carries *relational* information
  would require the support-set embeddings, which were never archived — only the aggregated
  direction was. The verdict is: no strong 1-D *entity*-decodable information.
- [CAVEAT] A 1-D projection is a strict information reduction; the probe tests for *strong*
  1-D-decodable information (10pp bar). Weak or distributed information would not clear it —
  but neither would it license a CONTINUE.

## Minor issues found and fixed (per founder order)

1. Over-tight float64 assertion tolerances (1e-9) on float32-normalized archived vectors
   (v_hat norm = 1−8.7e-8; min cone cos = 0.86602531 vs cos30° = 0.86602540) — relaxed to the
   float32-appropriate 1e-6. Artifact data untouched; the vectors are exactly as EXP077 built them.
2. First D1 design (label-built direction as gating positive control) was conceptually wrong:
   it conflated "machinery works" with "the bench has 1-D information" — the latter is what the
   probes test. Replaced with D1a (synthetic-data machinery check, gating) + D1b (label-informed
   direction, diagnostic only). The script documents this correction.
3. Imprecise shorthand in an earlier session note ("v_hat^c ⊥ mu") — the actual construction is
   `v_hat^c = normalize(Σ_k normalize(v_hat_k − mu))` with raw (non-unit) mu; archived
   cos(mu, v_hat^c) = −0.77, cos(v_hat, v_hat^c) = 0.68. The V7 probe uses the archived vector
   exactly; the interpretation above uses the correct construction.

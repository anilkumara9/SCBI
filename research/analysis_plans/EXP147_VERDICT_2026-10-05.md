## 4. Descriptive diagnosis (not re-barring — Law #9)

[OBSERVATION] The 0.0000 is a **format-compliance floor, not a capability floor.** Descriptive first-token analysis of the 180 B generations (the model almost always emits a name as its first generated token, then rambles for the remaining budget):

- Fraction of B generations whose **first normalized token == gold: 119/180 = 0.661**
- Per stratum: compositional-2hop 44/45 = 0.978; compositional-3hop 43/45 = 0.956; transitive-2hop 12/45 = 0.267; transitive-3hop 20/45 = 0.444
- Fraction of B generations that are short (≤2 normalized words): 0/180 — every generation rambled past the answer within the 15-token budget.

[INTERPRETATION] Pythia-410m (base, non-instruct) does not follow the "Answer with the name only" format: it emits a candidate name first, then continues the document. The registered scoring (full-generation exact match) gives zero credit for a correct leading name followed by rambling. The bench is not too hard — on compositional items the model's leading token is correct 96–98% of the time. What failed is the **measurement apparatus**: direct-answer format + strict full-generation scoring on a base LM that does not respect output format. The plan's material uncertainty #2 (base-LM instruction-following) is the realized failure mode, arriving through guard (d) rather than guard (e).

[INTERPRETATION] This HELD does not license any claim about the J7 hypothesis, the scratchpad discipline, or test-time compute. It licenses exactly one thing: a future proposal must fix the baseline measurement (e.g., first-token scoring, a stop sequence, or an instruct-tuned model) before the S/C comparison can be meaningful. That is a new proposal, not a repair of this verdict.

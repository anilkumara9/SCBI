## 1. Papers — steering / inference-time control / agents / memory

- **arXiv:2610.01969v1 — RASteer: Retain-Aware Activation Steering for Concept Erasure in Diffusion Models** (submitted Oct 1, 2026; VERIFIED via arxiv.org API). Training-free activation steering for concept erasure in diffusion models: builds a retain subspace from concepts to preserve, Retain-Orthogonal Steering removes aligned components from the erasure direction, Overlap-Adaptive Calibration balances erasure vs preservation per layer/step; matches/outperforms activation-steering and weight-editing baselines on unsafe-content/instance/style erasure. Summit relevance: LOW-MEDIUM — retain-subspace orthogonalization is a technique cousin of steering-direction disentanglement, but the domain is diffusion concept erasure, not LLM inference-time control.
  Source: https://arxiv.org/abs/2610.01969v1
- **arXiv:2610.01349v1 — PACE: Provenance-Aware Capability Enforcement for Tool-Using LLM Agents** (submitted Oct 1, 2026; VERIFIED via arxiv.org API). Mediates every tool call before execution (path confinement + capability/effect verification against authority from the authenticated request); strictly lowest attack success in 62/79 eligible attack columns across 8 agent-security benchmarks × 3 model families, 0/30 adaptive-search success, utility loss ≤3 points. Summit relevance: MEDIUM — safety infrastructure for tool-using agents; oversight-grade engineering to adopt if loop work touches tool use; no cognition claim.
  Source: https://arxiv.org/abs/2610.01349v1
- **arXiv:2610.01768v1 — LLMLeak: Covert Exfiltration Through Legitimate LLM Web Fetching** (submitted Oct 1, 2026; VERIFIED via arxiv.org API). Novel attack: local malware without internet embeds secrets in URLs and abuses the LLM's web-fetch tool as a covert channel; 79.7% attack success across 11 open-parameter models + real-chatbot case study. Summit relevance: LOW-MEDIUM (context) — raises the oversight bar for any SCBI agent-harness work; no new mechanism claim.
  Source: https://arxiv.org/abs/2610.01768v1
- **arXiv:2609.25537v1 — Context-to-Answer-Aligned Memory Compression** (submitted Sep 22, 2026; late catch surfaced this sweep; VERIFIED via arXiv abstract page). Compresses long contexts into Context Memory Embeddings aligned to any FROZEN decoder's embedding space — "without modifying decoder weights"; two-tier KV cache (question-guided CME selection + local window), answer-targeted distillation; up to +7.3 EM/+4.0 F1 on SQuAD, −20% inference time/energy, −50% peak GPU memory at 3K generation tokens across 9 encoder-decoder combos × 4 QA benchmarks. Summit relevance: HIGH — frozen-decoder-compatible inference-time memory compression is Δθ=0-adjacent; candidate technique for the selection/compression half of a future memory lane.
  Source: https://arxiv.org/abs/2609.25537v1
